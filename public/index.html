Setup Guide

1

Google Sheets — Product Catalogue

Create a Google Sheet with the following columns in row 1 as headers:

AB CD EF G
Name Code Description Unit CostPrice SellingPrice Category
Widget A WGT-001 Blue widget pcs 8.00 12.50 Widgets

Name the first sheet tab Products. Then copy the Sheet ID from the URL: …spreadsheets/d/SHEET_ID/edit…

2

Google Service Account

  1. Go to Google Cloud Console → APIs & Services → Credentials
  2. Create a Service Account, download the JSON key
  3. Enable the Google Sheets API for your project
  4. Share your Google Sheet with the service account email (Viewer role)
  5. Base64-encode the JSON key: base64 -i google-credentials.json | tr -d '\n'
  6. Paste the result as GOOGLE_CREDENTIALS_BASE64 in your .env
3

Telegram Bot

  1. Open Telegram and search for @BotFather
  2. Send /newbot and follow the prompts
  3. Copy the token and set it as TELEGRAM_BOT_TOKEN in your .env
  4. Restart the server — the bot will start in polling mode
Bot commands:
/start — Welcome message
/list — All products with selling prices
/price <name> — Search product price
/quote — Interactive quotation wizard → PDF → Email
4

Email (SMTP)

For Gmail, generate an App Password (not your account password):

  1. Google Account → Security → 2-Step Verification → App passwords
  2. Generate a password for "Mail"
  3. Set SMTP_USER and SMTP_PASS in your .env
